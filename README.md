# Ajwa of Madinah — Premium Dates Landing Page

A high-converting, luxury e-commerce landing page built for **Irfan Khairi Sdn Bhd** to showcase **"Ajwa of Madinah"** premium dates (200g).

## 🌟 Key Features
- **Luxury Aesthetic**: Deep black background with metallic gold accents.
- **Photoshoot Integration**: High-resolution product images and interactive 4-angle gallery.
- **Sunnah & Hadith Section**: Authentic Hadith quotes and historical context.
- **Nutrition Facts**: 100g nutritional breakdown with animated macronutrient bars.
- **Conversion Focused**: Direct routing to OnPay payment checkout, floating bottom buy bar, and FAQ accordion.
- **Zero Dependencies**: Pure HTML5, Vanilla CSS3, and Vanilla JavaScript.

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   ```
2. Open `index.html` directly in any web browser, or place inside your local web server (e.g., `XAMPP/htdocs`).
